# Figma elicitation UI kit

This directory preserves the reusable UI extracted from Figma node `40:114359`:

- 768 x 332 responsive elicitation panel
- 28px panel radius and token fallbacks
- 56px numbered choice rows
- Progress, custom-answer, and Skip affordances
- Exact exported chevron and edit SVG assets

These files are design assets, not an active MCP App. Nothing in this directory is registered by `server.ts`. Reuse them when a specific complex COACH task has a reviewed interactive state; routine coaching stays in the Microsoft 365 Copilot conversation.
